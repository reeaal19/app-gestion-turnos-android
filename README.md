# 📅 App de Gestión de Turnos

Aplicación móvil nativa para Android desarrollada como proyecto práctico para facilitar la organización de calendarios y turnos de trabajo.

## 🚀 Características principales
* Visualización de calendario mensual con turnos asignados.
* Gestión y creación de diferentes tipos de turnos (mañana, tarde, noche).
* Interfaz de usuario intuitiva.

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Kotlin
* **Entorno de Desarrollo:** Android Studio
* **Arquitectura / UI:** XML
